Descripción

Hola, comparto con ustedes algunos de mis primeros archivos PKG para PS4. El archivo .pkg está listo para que lo instalen y prueben directamente en sus consolas usando GoldHEN . Es una recreación de forma libre de una ubicación del mundo real en Nepal, creada usando datos de elevación reales y texturas satelitales; fue desarrollada en Unity 2017 usando el SDK de PS4. El entorno está diseñado para la exploración y para observar cómo la consola maneja la carga de este tipo de datos geográficos. Detalles del Homebrew: Plataforma: PS4 (Requiere GoldHEN). Motor: Unity 2017. Contenido: Entorno de exploración 3D basado en el terreno real de Nepal, alrededor del Monte Everest. Texturas sat 8k. Formato: Archivo .pkg listo para la instalación. .incluye una capa de nubes cirrus y un par de otras opciones, como cambiar la textura del terreno, además de la capacidad de medir la altura real de las montañas si presiona Triángulo. (La cámara tiene movimiento completo y sin restricciones y puede atravesar el terreno, lo que puede resultar en una apariencia poco atractiva o antinatural; la he dejado así para esta versión inicial. Presione Cuadrado para cambiar la textura del terreno; esto puede tardar unos segundos, así que por favor espere un momento mientras se cargan y aplican las texturas).
